# 🏗️ ArchBuild Enterprise SaaS - Complete Procurement & Proposal Suite

An enterprise-grade SaaS platform for architects, interior designers, and civil engineers featuring:
1. **Multi-Project Management & SQLite Database Persistence**
2. **Itemized BOQ Calculation & Interactive Charts**
3. **Multi-Vendor Price Comparison Engine**
4. **Automated Purchase Order (PO) Generator & Export**
5. **Professional Client PDF Quotation / Proposal Generator (ReportLab)**

---

## 🛠️ How to Run Locally

1. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
2. **Run the App:**
   ```bash
   streamlit run app.py
   ```
